Academic Agent Privacy Policy

Effective Date: September 17, 2026

1. Operational Philosophy & Scope

Academic Agent is an open-source productivity operating layer designed specifically for academic environments. We prioritize student privacy and local-first data ownership. The platform is not an institutional ERP, does not sell student records, and does not conduct tracking or behavioral analytics.

2. Information We Process

  • Account Credentials: Email address, user name, and salted cryptographic password hashes (PBKDF2-HMAC-SHA256). Passwords are never stored in plaintext.
  • Google Classroom Data: Enrolled course names, coursework titles, assignment instructions, deadlines, and submission identifiers retrieved solely through authorized Google OAuth 2.0 scopes.
  • Course Materials & Deliverables: PDF, DOCX, TXT, and source code files uploaded by the user or generated on the user's behalf. Files remain within the user's isolated tenancy.
  • Timetable Records: Class schedules, timings, and classroom locations supplied directly by the student.

3. Google OAuth & Token Handling

When you connect Google Classroom, OAuth access tokens and refresh tokens are stored locally in the secured application database. Tokens are utilized strictly to query course rosters, list coursework, upload assignment files to your Google Drive, and record authorized turn-ins. Tokens are never transmitted to third parties, external tracking networks, or commercial aggregators.

4. Security & Data Isolation

Every database record is scoped to the individual user. Multi-tenant authorization checks prevent cross-user data access (IDOR). File operations are strictly path-bounded to eliminate directory traversal risks. Rate-limiting and enterprise security headers (CSP, HSTS, X-Frame-Options) are enforced on all HTTP responses.

5. Data Retention & Deletion

You maintain full ownership of your data. Disconnecting Google Classroom purges OAuth credentials immediately. Users may delete course materials, generated assignments, and account records at any time.

6. FERPA & Educational Record Compliance

Academic Agent adheres to FERPA (Family Educational Rights and Privacy Act) standards by ensuring student educational records, assignments, and course materials are strictly tenant-isolated and never shared with unauthorized parties.

7. Contact & Open Source Auditing

Academic Agent is open-source software. You may inspect the complete security implementation and database models in the repository. For inquiries or security disclosure, submit an issue on the project repository.
