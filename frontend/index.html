Google Cloud OAuth Setup Guide If you see redirect_uri_mismatch or access_denied when signing in:
  1. Open Google Cloud Console → APIs & Services → Credentials.
  2. Edit your Web Client ID and add these to Authorized redirect URIs:
    http://localhost:8000/api/auth/google/callback
    http://127.0.0.1:8000/api/auth/google/callback
  3. Under OAuth consent screen → Test users, ensure your Gmail is added.
